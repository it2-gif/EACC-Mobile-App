# EACC Connect redirect

This repository contains only a redirect and compatibility files for the former web address.

The application is hosted at https://eacc-mobile-app.web.app/. Sign in using your usual LMS account.

No application source, credentials, account records or chat data belong in this repository. Existing cached/offline shortcuts may need a refresh before the bridge is fetched. No notifications are broadcast and no browser data is deleted by this bridge.
